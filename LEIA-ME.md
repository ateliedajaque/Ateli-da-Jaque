# Site do Ateliê da Jaque (rascunho)

Site estático (HTML, CSS e JavaScript puro). Não precisa de servidor nem de banco de dados, então pode ser publicado de graça (GitHub Pages, Netlify ou Cloudflare Pages).

## Arquivos
- `index.html` — a página (início, destaques, cardápio, avisos, contato) com as tags de SEO e de pré-visualização para Instagram/WhatsApp.
- `js/cardapio.js` — **todos os produtos, preços, sabores e avisos**. Para atualizar o cardápio, mexa só aqui.
- `js/app.js` — filtros do cardápio, montagem do pedido e mensagem pronta para o WhatsApp.
- `css/estilo.css` — visual (preto e dourado, como o cardápio impresso).
- `img/` — fotos recortadas do cardápio em PDF. `og-ateliedajaque.jpg` é a imagem que aparece quando o link é compartilhado.
- `robots.txt` e `sitemap.xml` — para o Google encontrar o site.

## Para aparecer no Instagram e no Google
- Colocar o link do site na bio do @ateliedajaque27 e no botão de contato.
- Cadastrar o site no Google Search Console e enviar o `sitemap.xml`.
- Criar o Perfil da Empresa no Google (Google Meu Negócio) com o link do site: é o que faz o ateliê aparecer em buscas como "docinhos para festa perto de mim" e no Google Maps.
